# Orbit

画像やPDFをPC内で変換するデスクトップアプリです。ファイルをドラッグしながらShiftを押すと、円形メニューから変換先を選べます。

[ZIPをダウンロード](https://github.com/Pokare/orbit/releases)

| OS | 配布ファイル | 対応環境 |
| --- | --- | --- |
| macOS | Orbit-Mac | Appleシリコン、macOS 13以降 |
| Windows | Orbit-Windows-x64 | Windows 11、Intel・AMD |
| Windows | Orbit-Windows-Arm64 | Windows 11、Arm64 |

ZIPを解凍して、Macは `Orbit.app`、Windowsは `Orbit.exe` を開きます。Mac版は動画や音声の変換、画像の切り抜きなどにも対応します。一部の変換にはFFmpegやLibreOfficeが必要です。Windows版は画像・PDFが対象です。

プレリリースです。Mac版はAppleの公証を受けていません。Windows版は未署名です。環境によって初回起動時にOSが警告を表示することがあります。

Mac版は Adithya の Shift（MIT）をベースにしています。上流と同梱ライブラリのライセンス表記は配布ファイルに収録しています。
